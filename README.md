# 我的工作台

一个面向个人使用、可逐步扩展的本地 B/S 工作台。首版通过 EpointMsg 的本机 MCP 服务，将本人私聊和群聊历史归档到 SQLite，在浏览器中查看、搜索和导出，为后续自行分析提供本地数据素材。

首版三个实施阶段均已人工审核通过。前端包版本为 `0.1.0`；“首版”不表示已创建 Git release 或版本标签。

仓库：<https://github.com/dwarf471/Workbench>

## 功能范围

- 连接设置：配置来源标识、显示名称、MCP 地址和客户端配置路径，检查握手及工具列表。
- 手动同步：发现最近会话、查找联系人或群组、跨页选择，按最近 30 天、自定义时间或全部可获取历史创建任务。
- 任务管理：串行后台执行、分页事务入库、去重、查看进度、取消和断点继续。
- 聊天归档：会话与消息浏览，私聊/群聊筛选，名称、文本和文件名搜索，发送者及时间过滤。
- 搜索上下文：定位消息所在页并高亮目标消息。
- 数据输出：按查询范围导出 JSON/CSV，创建和下载完整 SQLite 在线备份。

首版不包含定时自动同步、AI 调用、语义搜索、媒体下载或转写、远程访问认证及在线数据库恢复。

首版后的需求提取扩展已完成，三个步骤均已人工审核通过：大模型设置、时间范围提取及候选预览、人工确认登记与 CSV 清单恢复。模型凭证使用 Windows 当前用户 DPAPI 加密保存到 `data/model.local.json`，不提交 Git。详见 [步骤 1](requirement-extraction-step-1-review.md)、[步骤 2](requirement-extraction-step-2-review.md) 和 [步骤 3 审核说明](requirement-extraction-step-3-review.md)。阶段文档保留交付时的历史状态，最终均已审核通过。

提取使用最后一次成功查询的会话及起止时间，忽略关键词/发送者过滤，分析范围内全部可用文字。发送前须明确确认；外部模型收到聊天文本，HTTP 接口存在明文传输风险。图片和附件实体不解析，模型结果须人工核对，不自动登记。快照、候选及已确认需求保存在 SQLite 中，当前迁移版本为 `0004`，也会进入完整数据库备份。

## 需求提取与备案

1. 配置大模型基础地址、模型名称和凭证，完成固定文本连接测试。远程与本机均支持 HTTP/HTTPS，优先使用 HTTPS。
2. 在会话浏览选择会话及日期范围并查询，点击提取需求，核对范围和模型地址后确认发送。
3. 等待后台分析，核对候选及来源原文，修改概述和待确认事项，勾选需要备案的需求。
4. 点击登记需求，查看重复/相似提示，人工确认后写入登记簿和 `data/requirements/需求清单.csv`。
5. 在顶部需求清单中查看全部来源的登记记录，下载或重新生成 CSV。

CSV 使用 UTF-8 BOM，一项需求一行，含概述、备注、时间范围和来源编号，时间显式使用 `+08:00`。完全重复项跳过，疑似相似由人工判断；备案默认状态待评审。登记后任务候选锁定，未勾选项不登记，不提供修改或撤销已备案记录的入口。

数据库是登记依据，CSV 是可恢复的输出。文件写入失败时已完成的备案保留，关闭占用程序后重新生成，不重复新增。检测到外部修改时保留原 CSV 并拒绝覆盖，先另存或移走文件再生成；手工 CSV 修改不会导入数据库。清单及备份含私人资料，不加密、不提交 Git。登记、清单查看和下载不会调用模型或 MCP。

## 环境要求

- Windows 与 PowerShell；终端可以执行 `python` 和 `npm.cmd`。
- 建议使用 Python 3.11 或更新的兼容版本、Node.js 22 LTS。
- 安装依赖需要网络。
- 同步新消息需要 EpointMsg 已登录本人账号，且本机 MCP 服务和已有令牌可用。工作台不会安装或开启客户端 MCP，也不会生成或重置令牌。

已归档数据的浏览、搜索、导出和备份不要求新点客户端在线。

## 安装与启动

```powershell
git clone https://github.com/dwarf471/Workbench.git
cd Workbench
.\start.cmd
```

也可在项目根目录双击 `start.cmd`。脚本会创建 `backend/.venv`、安装后端与前端依赖、校验并构建前端，然后启动服务；每次通过脚本启动都会执行安装和构建。

打开 <http://127.0.0.1:8765/>。服务仅监听本机；保持终端运行，按 `Ctrl+C` 停止。端口被占用时脚本会提示并停止，不会结束其他进程；若已有工作台运行，直接访问原地址。

依赖和前端构建已就绪时，可在项目根目录直接启动：

```powershell
.\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8765 --no-access-log
```

应用启动自动升级数据库迁移；更新代码前建议备份已有数据。

## 首次使用

1. 在连接设置填写来源标识和显示名称。
2. 核对 MCP 地址，默认 `http://127.0.0.1:9527/mcp`，以客户端实际端口为准；核对客户端配置路径。
3. 保存并检查连接，确认握手和工具列表可用。
4. 在同步管理发现会话或查找联系人/群组，首次建议选择一个私聊、一个群聊及较小的自定义时间范围。
5. 确认新点当前登录账号与来源一致，创建任务并查看进度。
6. 在聊天归档选择来源及会话，浏览、搜索或导出消息。

## 连接与同步规则

连接页可以修改账户显示名称、MCP 地址及客户端配置路径。保存只写入项目根目录的 `workbench.local.json`，不会修改新点配置。检查连接只执行 initialize 和 tools/list，不调用聊天工具。默认读取当前 Windows 用户 APPDATA 下 EpointMsg/setting_rong.json，令牌在内存中按客户端算法解密，不持久化，不返回给浏览器。Python 不可变字符串无法保证彻底清除内存副本。

来源账户标识用于隔离不同账号的归档，只能使用字母、数字、下划线和连字符；账户名称是显示标签。MCP 不提供可靠的当前账号身份查询，每次创建或恢复任务都须人工确认新点登录账号与来源一致。切换账号时先取消现有任务，再在连接设置中切换来源标识。切换新点账号本身无法被工作台自动检测。

数据库位于 data/workbench.sqlite3，迁移 0002 增加 conversations、messages、sync_tasks、sync_items。手动同步由后端单个后台 worker 串行执行，不依赖页面持续打开；后端停止或重启后未完成任务标记为已中断，不自动继续。每页数据及游标原子提交，取消不会写入尚未提交的返回页面。活动任务存在时不允许通过 API 修改连接配置。

## 浏览与分析素材

首页为聊天归档。按来源选择归档账号，左侧会话名称支持自动子串搜索与私聊/群聊筛选；右侧消息按时间倒序分页，消息时间直接使用客户端保存的可读时间。发送者姓名缺失时显示来源 ID。

全局搜索覆盖当前选定来源的所有已归档会话，不跨来源隐式混查。关键词支持中文连续短语，以及文件名；采用字面子串匹配，英文区分大小写，% 和 _ 不作为通配符。不做分词、相关度排序或语义搜索。发送者按姓名或 ID 子串筛选。日期范围按浏览器本地时区取开始日 00:00:00.000 至截止日 23:59:59.999，包含起止边界；查询、导出和需求提取使用同一整日范围。搜索结果可以定位到消息所在页并查看上下文；定位会清除搜索条件。

导出菜单提供 JSON、CSV，遵循最近一次查询结果的范围，导出全部匹配记录而不是仅当前页。未点击查询的新输入不改变导出范围。JSON 保留过滤条件与清洗后的消息元信息；CSV 使用 UTF-8 BOM，并对公式前缀进行防护。导出文件含私人聊天，应自行选择是否提供给 AI；本版不调用 AI 模型，不向外部服务发送聊天。

浏览、搜索和导出只读取 SQLite，不调用 MCP。新点关闭后已归档数据仍可使用，但未同步的内容不会自动出现。消息内容安全转义，不执行 HTML，不加载远程媒体，也不提供任意本地路径访问接口。

## 数据库备份与同步限制

页面的备份数据库会保存并下载所有来源的完整数据库，不受当前搜索筛选限制。也可运行根目录 backup.cmd，或在 backend 目录运行 `.venv/Scripts/python.exe -m app.backup`。

备份通过 SQLite 在线备份接口生成，支持 WAL 模式及服务运行中备份，生成后执行 integrity_check。文件使用唯一名称，保存于 data/backups，不覆盖之前的备份。不备份新点自身配置、令牌、媒体实体或 workbench.local.json。数据库与备份均为本机明文文件，须按私人资料保管；本版不提供自动删除备份或在线恢复操作。恢复前必须停止服务并保留原始数据库，不能在服务运行时直接覆盖数据库文件。

会话发现只展示名称、类型和 ID，不持久化未选择的会话，不传递消息预览。最近会话列表不是全量会话目录，联系人查找也受客户端缓存/群组搜索能力限制。每个任务最多 100 个会话，可选最近 30 天、自定义时间和全部可获取历史。请求结束时间固定在任务创建时，任务结束不代表完整云端备份。

分页使用毫秒时间游标并重叠时间边界，游标停滞、空页却仍有更多数据或达到 10000 页上限会标记警告。失败或中断可从已提交断点继续；警告重试会重新从任务范围顶部拉取，不能保证消除客户端本身的分页限制。拉取计数包含重叠页，新增计数为实际入库条数。消息优先按来源唯一 ID 去重，没有 ID 时按时间、发送者、类型、方向及内容摘要去重；完全不可区分的无 ID 消息可能合并。

保存的消息含文本、发送者、客户端可读时间、原始毫秒时间及清洗后的消息 JSON。媒体只保存元信息和可用路径/链接，不下载，不转写，不做在线预览。敏感凭证字段递归清洗；不记录原始工具错误到日志。

服务没有远程访问认证，**不要改为 `0.0.0.0` 监听，也不要通过代理或端口转发对外开放**。

## 常见问题

- **端口被占用**：先确认是否已有工作台运行；脚本不会终止占用端口的进程。
- **令牌读取失败**：核对配置路径、已有令牌和客户端版本；算法变化可能导致解密失败。
- **连接失败或未授权**：确认客户端已登录、MCP 端口正确、服务在线且令牌有效。
- **同步数量少于预期**：核对账号、时间范围和任务警告；客户端历史范围及分页能力可能有限。
- **重启后任务没有继续**：这是预期行为，确认客户端账号后手动继续。
- **搜索不到新消息**：搜索只针对本地库，需先显式创建同步任务。

后续功能继续按明确范围、实施验证、人工审核的方式逐步扩展。
